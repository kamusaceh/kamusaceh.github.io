# City Builder 3D

Prototype pembangun kota 3D berbasis browser untuk GitHub Pages.

## Fitur awal
- Kamera 3D: putar, geser, dan zoom.
- Pilih rumah, kantor, menara, atau taman.
- Klik area tanah untuk menempatkan objek.
- Mode hapus untuk menghilangkan objek.
- Detail kecil bangunan disederhanakan saat kamera menjauh (LOD dasar).
- File dipisah menjadi HTML, CSS, dan JavaScript.

## Menjalankan
Buka:
`https://kamusaceh.github.io/city-builder-3d/`

Three.js dan OrbitControls dimuat dari jsDelivr, jadi koneksi internet diperlukan.

## Pengembangan berikutnya
- Penyimpanan kota dan pemuatan ulang bangunan.
- Model GLB untuk bentuk bangunan yang lebih realistis.
- Streaming tile/area kota berdasarkan jarak kamera.
- Sistem pemilihan, pemindahan, rotasi, dan pengaturan ukuran bangunan.

Catatan: ini adalah fondasi/prototipe awal, belum merupakan simulasi kota lengkap.
